One word, the first that comes to mind. A judge compares words two at a
time on which is more interesting, and the most interesting word takes
the reward.

This entry's word is **defenestration** — the act of throwing someone
out of a window. Surprising, vivid, and witty: a whole scene smuggled
into a single word.

Run it with Node 22.18+ (the grader runs Node 22.23.4):

```sh
node main.ts
```

It writes exactly one word to `/output/entry.txt`, deterministically,
with no network access and no external dependencies.
